## Что это значит практически
1. **Shopify (W-01)** — сейчас стреляет через Flow B (классическая форма) и частично через Flow A; Flow A — мина с известным сроком (удаление `checkouts` в 2026). Миграция: Cart API (`/cart/add.js` уже используется) + Checkout/cart-permalink, без `unstable/graphql`.
2. **Stripe ctoken (W-02)** — серверный путь с pk работает (живые 200 в журнале), но он вне контракта: при закрытии вернётся 404/400, и чекаут Woo развалится без явной ошибки. Нужен алерт и второй контур.
3. **Капчи (W-04/W-05)** — Altcha v3 memory-bound делает CPU-брутфорс невыгодным: локальный солвер перестаёт масштабироваться; единственный устойчивый путь для v3 — браузерный (patchright, W-08) или внешний солвер.
