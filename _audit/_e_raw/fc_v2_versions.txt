page</button></div><div class="theme-doc-markdown markdown"><header><h1>v1 and v2</h1></header>
<p>There are two versions of the Friendly Captcha service, called <strong>v1</strong> and <strong>v2</strong>. The second version contains technical and non-technical enhancements that come from state-of-the-art improvements and learnings from <strong>v1</strong>.</p>
<h2 class="anchor anchorWithStickyNavbar_LWe7" id="whats-new-in-v2">What&#x27;s new in v2?<a href="#whats-new-in-v2" class="hash-link" aria-label="Direct link to What&#x27;s new in v2?" title="Direct link to What&#x27;s new in v2?">​</a></h2>
<ul>
<li>v2 has <strong>improved protection</strong>. It provides us with more powerful signals to detect abuse, automated browsers, and browsers that have otherwise been tampered with.</li>
<li>v2 improves on <strong>user experience</strong>. Real users are less likely to need to wait for the captcha to finish.</li>
<li>v2 is <strong>easier to integrate</strong>. It has SDKs for many popular programming languages, automatically matches the language of your website, and has simplified Content Security Policy (CSP) requirements.</li>
</ul>
<h2 class="anchor anchorWithStickyNavbar_LWe7" id="what-hasnt-changed">What hasn&#x27;t changed?<a href="#what-hasnt-changed" class="hash-link" aria-label="Direct link to What hasn&#x27;t changed?" title="Direct link to What hasn&#x27;t changed?">​</a></h2>
<ul>
<li>Friendly Captcha protects your websites and apps from bots and abuse.</li>
<li>There are no user tasks like clicking cars, and there are no cookies or user tracking involved.</li>
<li>It supports the same old browsers like Internet Explorer 11.</li>
<li>It offers an EU-only infrastructure option, where we guarantee your users&#x27; data does not touch any US-owned server.</li>
<li>The code that runs in your website is <a href="https://github.com/FriendlyCaptcha/friendly-captcha-sdk" target="_blank" rel="noopener noreferrer">open source</a>, so you can be certain you will not be compromised even if we were to get compromised.</li>
</ul>
<h2 class="anchor anchorWithStickyNavbar_LWe7" id="whats-going-to-happen-to-v1">What&#x27;s going to happen to v1?<a href="#whats-going-to-happen-to-v1" class="hash-link" aria-label="Direct link to What&#x27;s going to happen to v1?" title="Direct link to What&#x27;s going to happen to v1?">​</a></h2>
<p>v1 will keep working! We will maintain it moving forward for multiple years.</p>
<p>At some point down the road we will not allow newly created apps to use v1, but existing apps will still continue to work.</p>
<h2 class="anchor anchorWithStickyNavbar_LWe7" id="how-do-i-upgrade">How do I upgrade?<a href="#how-do-i-upgrade" class="hash-link" aria-label="Direct link to How do I upgrade?" title="Direct link to How do I upgrade?">​</a></h2>
<p>v2 is available to all customers and we highly recommend it. Please <a href="/docs/v2/guides/upgrading-from-v1">follow the upgrade guide</a>.</p>
<p>If you&#x27;re an <strong>Enterprise</strong> customer, please <a href="https://friendlycaptcha.com/support/" target="_blank" rel="noopener noreferrer">contact support</a> so that we can help you upgrade to v2!</p>
<h2 class="anchor anchorWithStickyNavbar_LWe7" id="how-can-i-tell-if-im-using-v1-or-v2">How can I tell if I&#x27;m using v1 or v2?<a href="#how-can-i-tell-if-im-using-v1-or-v2" class="hash-link" aria-label="Direct link to How can I tell if I&#x27;m using v1 or v2?" title="Direct link to How can I tell if I&#x27;m using v1 or v2?">​</a></h2>
<p>There are a couple of features that you can use to identify which version you&#x27;re using. Firstly, the widget that goes on your website or app looks different.</p>
<div style="display:flex"><div style="text-align:center"><b>v1 Widget</b><img src="/img/widget-v1-ready.png" style="width:100%"><img src="/img/widget-v1-completed.png" style="width:100%"></div><div style="text-align:center"><b>v2 Widget</b><img src="/img/widget-v2-ready.png" style="width:100%"><img src="/img/widget-v2-completed.png" style="width:100%"></div></div>
<p>Secondly, the URLs that you use are different between v1 and v2.</p>
<p><strong>v1 URLs</strong></p>
<ul>
<li>Widget SDK script: <code>https://cdn.jsdelivr.net/npm/<a href="/cdn-cgi/l/email-protection" class="__cf_email__" data-cfemail="d1b7a3b8b4bfb5bda8fcb2b9b0bdbdb4bfb6b49189ff88ff8b">[email&#160;protected]</a>/widget.module.min.js</code>.</li>
<li>NPM package: <a href="https://www.npmjs.com/package/friendly-challenge" target="_blank" rel="noopener noreferrer"><code>friendly-challenge</code></a>.</li>
<li>Verification API endpoint: <code>https://api.friendlycaptcha.com/api/v1/siteverify</code>.</li>
</ul>
<p><strong>v2 URLs</strong></p>
<ul>
<li>Widget SDK script: <code>https://cdn.jsdelivr.net/npm/@friendlycaptcha/<a href="/cdn-cgi/l/email-protection" class="__cf_email__" data-cfemail="4132252a01196f186f1b">[email&#160;protected]</a>/site.min.js</code>.</li>
<li>NPM package: <a href="https://www.npmjs.com/package/@friendlycaptcha/sdk" target="_blank" rel="noopener noreferrer"><code>@friendlycaptcha/sdk</code></a>.</li>
<li>Verification API endpoint: <code>https://global.frcapi.com/api/v2/captcha/siteverify</code></li>
