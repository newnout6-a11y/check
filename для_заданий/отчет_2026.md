## 1. TLS-отпечатки и библиотека curl_cffi

### 1.1. Текущая реализация в PUSTO
В config.py зафиксирован ограниченный кортеж:
IMPERSONATIONS = ('chrome116', 'safari17_0', 'chrome110', 'safari18_0', 'chrome107', 'safari17_2_ios', 'firefox133', 'chrome100', 'edge101', 'safari15_5', 'chrome99', 'edge99', 'tor145')

### 1.2. Возможности установленной curl_cffi 0.15.0
Прямой опрос curl_cffi.requests.BrowserType показал наличие современных профилей:
- **Chromium**: chrome133a, chrome136, chrome142, chrome145, chrome146, chrome131_android.
- **Safari / WebKit**: safari184, safari184_ios, safari260, safari260_ios, safari2601.
- **Gecko / Firefox**: firefox135, firefox144, firefox147.
- **Rolling-алиасы**: impersonate='chrome', impersonate='safari', impersonate='safari_ios'.
- **Утилита обновления**: команда curl-cffi update / curl-cffi list позволяет скачивать актуальные базы отпечатков без переустановки пакета.

### 1.3. Выявленные риски текущего кода
1. **Возраст профилей**: chrome99–chrome110 — это версии 2022–2023 годов. В 2026 году появление таких браузеров в регулярном трафике триггерит антифрод-системы (Cloudflare, DataDome).
2. **Пассивный OS Fingerprinting (p0f / TCP Mismatch)**:
   - В curl_cffi профиль chrome по умолчанию эмулирует macOS (UA и Sec-Ch-Ua-Platform: 'macOS').
   - На Windows хосте сетевой стек отправляет TCP SYN пакеты с Windows TTL=128 и специфичным порядком опций. Несовпадение OS в User-Agent и TCP стеке — явный сигнал автоматизации.
   - Решение: использование профиля edge (несет нативный Windows User-Agent) либо согласованная подмена заголовков платформы.
3. **Остаточный хардкод**: ot/gates/braintreenvbv.py:62, scratch/dork_harvester.py:149, scratch/deep_dorker.py:155 содержат прямой chrome131 в обход ротации.

## 3. Современные Stealth-решения и архитектура запросов

### 3.1. Структура многоуровневой защиты (WAF 2026)
1. **L3/L4**: IP/ASN репутация (датацентр vs резидентные), TCP p0f фингерпринт.
2. **TLS / HTTP2**: JA4 отпечаток, согласованность HTTP/2 SETTINGS фреймов и псевдо-заголовков.
3. **JS Challenge / PoW**: вычисление proof-of-work в фоне без капчи.
4. **Managed Turnstile**: интерактивный виджет (требует эмуляции браузера CDP/SeleniumBase UC).

### 3.2. Почему архитектура PUSTO S0->S2 эффективна
- Пассивная квалификация (S1) делает 3 GET-запроса без мутаций, что не расходует репутацию прокси и не вызывает аномалий в поведении корзины.
- При обнаружении CF_CHALLENGE цель сразу штрафуется, исключая повторные блокировки.
