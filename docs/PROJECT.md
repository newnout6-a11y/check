# PUSTO ENGINE — ЕДИНАЯ АРХИТЕКТУРНАЯ ДОКУМЕНТАЦИЯ

> **Статус документа**: Актуальный мастер-документ проекта. Единственный источник правды по архитектуре, платёжным шлюзам, прокси-слою, структуре базы данных и Telegram-боту. Все разрозненные исторические файлы аудитов и черновиков сведены сюда.

---

## 1. Назначение и стек

**PUSTO** — высокопроизводительный асинхронный чекер карт и движок платёжной авторизации.

- **Среда выполнения**: Python 3.14 (Windows 11 / Linux).
- **Сетевой стек**: `curl_cffi` с динамической ротацией TLS/JA3/JA4 отпечатков реальных браузеров (`pick_impersonate()`: ротация Chrome, Safari, Firefox, Edge, Tor для обхода Cloudflare 429).
- **Бот-платформа**: `pyrogram` 2.2+ (асинхронный MTProto клиент Telegram).
- **База данных**: SQLite3 с включённым режимом WAL (`bot/bot_users.db`, схема v2).
- **Пул данных**: локальные JSON и TXT носители в каталоге `data/`.

---

## 2. Платёжные шлюзы и векторы проверки

Все шлюзы подключены в единый реестр `bot/main.py` и доступны как через слэш-команды, так и через интерактивные кнопки меню и прямой ввод карт.

| Команда | Имя модуля | Стоимость | Механика и рабочий контур |
|---|---|---|---|
| `/st` (или `/st1`, `/st5`, `/st20`) | `storegate` | 2 кр. | **WooCommerce Store API**: прямое добавление в корзину + чекаут через `cart/extensions`. Авто-подбор товара по тиру цены. Приоритет №1. Цели: `data/store_targets.txt`. |
| `/sp` (или `/sp1`, `/sp5`, `/sp20`) | `shopify` | 2 кр. | **Shopify Vault**: токенизация PAN через `deposit.us.shopifycs.com` + GraphQL Storefront Cart/Checkout One. Цели: `data/shopify_targets.txt`. |
| `/au` | `setupwoo` | 1 кр. | **Stripe $0 SetupIntent**: авторизация без списания баланса карты через `admin-ajax.php` (`wc_stripe_upe`). Доноры: `data/ready_gates.json`. |
| `/hit` | `cmd_hit` | 2 кр. | **Stripe Checkout Direct**: оплата по активным ссылкам чекаута `cs_live_...`. |
| `/pi` | `piconfirm` | 1 кр. | **PaymentIntent Confirm**: прямое подтверждение открытых секретов `pi_..._secret_...`. |
| `/vbv` | `braintreenvbv` | 1 кр. | **Braintree 3DS / Non-VBV**: проверка на наличие 3D Secure челленджа. |
| `/chk` | авто-выбор | по шлюзу | **Умный авто-мультигейт**: перебирает живые шлюзы в порядке `GATE_PRIORITY`. |

### Порядок авто-выбора (`GATE_PRIORITY`)
```python
GATE_PRIORITY = ["storegate", "setupwoo", "shopify", "piconfirm", "braintreenvbv"]
```
При авто-проверке (`/chk` или прямая отправка карты) движок в первую очередь использует `storegate` (как самый стабильный рабочий контур). При сбое цели происходит прозрачный переход к следующему гейту.

## 3. Ценовые тиры (Price Tiers)

Используются в `storegate` и `shopify` для ограничения максимальной суммы проверочной транзакции:

- **Tier 1 (`1` / `low`)**: товары до **$1.00** (микрочеки от $0.10 до $1.00).
- **Tier 5 (`5` / `mid`)**: товары от **$1.01 до $5.00** (оптимальный баланс наличия товаров и проходимости).
- **Tier 20 (`20` / `high`)**: товары от **$5.01 до $20.00** (максимальный охват магазинов).
- **Auto / All**: отключение фильтра цены (до $20.00).

Выбранный тир сохраняется в профиле пользователя в базе данных (`selected_tier`) и автоматически применяется при чеках.

## 4. Прокси-инфраструктура и защита от сбоев

### 4.1. Экспертный приоритет протоколов
1. **SOCKS5 (множитель 2.0x)** — абсолютный приоритет. Чистый TCP-туннель без внедрения HTTP-заголовков (`Via`, `X-Forwarded-For`), идеален для браузерной эмуляции TLS в `curl_cffi`.
2. **HTTP / HTTPS (1.0x)** — рабочий CONNECT-туннель.
3. **SOCKS4 (0.8x)** — резервный вариант.

### 4.2. Алгоритм скоринга и выбора (`proxy_manager.py`)
```python
weight = ((1000.0 / max(latency_ms, 20)) ** 2) * proto_mult / (1.0 + fail_count * 2.0)
```
- Прокси выбираются взвешенно среди ТОП-35% самых быстрых живых узлов.
- Узлы с 3 страйками ошибок исключаются из пула.
- Функция `gc.pick_proxy()` выбирает **только подтверждённые живые узлы** из `data/proxy_health.json`. Если проверенных прокси нет, возвращается `None` (безопасное прямое подключение).

### 4.3. Авто-фоллбэк при блокировках Cloudflare
Если публичный прокси заблокирован Cloudflare на мерчанте (`no Nonce`, `403`, `connection closed`, `curl (97/7/28)`):
1. Прокси моментально штрафуется и помечается сбойным в `data/proxy_health.json`.
2. Движок автоматически повторяет запрос напрямую или через резервный узел.
3. **Чек пользователя никогда не срывается из-за сбоя прокси.**

### 4.4. Фоновая валидация и чистка
- Каждые 15 минут бот в фоновом режиме запускает валидацию пула (до 80 асинхронных воркеров) и атомарно очищает `data/proxies.txt` от мёртвых узлов.

## 5. Telegram-бот и интерактивное управление (`bot/main.py`)

### 5.1. Управление через кнопки (Inline Keyboards)
- **Главное меню**:
  - `[ 💳 Быстрая проверка карты ]` — подсказка и переход в режим ввода.
  - `[ 🎯 Шлюз: ... ]` — меню смены активного шлюза с сохранением в БД.
  - `[ 💰 Цена: ... ]` — меню переключения ценового тира (Tier 1 / 5 / 20).
  - `[ 📊 Мой профиль ]` — баланс кредитов, статус (Free/Premium), статистика проверок и хитов.
  - `[ 🧩 Шлюзы и пулы ]` — онлайн-монитор состояния доноров и мерчантов.
  - `[ 📡 Прокси-пул ]` — проверка пула, замер задержки, удаление мёртвых узлов.
  - `[ 📁 Массовый чек ]`, `[ 🔍 BIN Lookup ]`, `[ 🎟 Активация ключа ]`, `[ ℹ️ Справка ]`.
- Все меню работают через `CallbackQuery` без спама новыми сообщениями (`edit_message_text`).

### 5.2. Прямой ввод карты и файлов без команд
Если отправить данные прямо в чат:
- `4111 1111 1111 1111 12 28 123` или `4111111111111111|12|28|123` ➔ бот моментально запускает проверку с текущими настройками шлюза и цены.
- 6 цифр (например, `411111`) ➔ автоматический запуск BIN Lookup.
- Список карт (до 20 шт.) или `.txt` с картами ➔ запуск массового чека.
- Документ `.txt` со списком прокси ➔ интеллектуальный роутинг в добавление и валидацию прокси-пула.

## 6. База данных (`bot/db.py`)

- Файл: `bot/bot_users.db` (SQLite3 WAL).
- Текущая схема: **`SCHEMA_VERSION = 2`**.
- Таблицы:
  - `users`: `user_id`, `username`, `credits`, `total_checks`, `hits`, `premium_until`, `created_at`, `selected_gate` (TEXT DEFAULT 'chk'), `selected_tier` (TEXT DEFAULT '1').
  - `keys`: `key`, `days`, `credits`, `created_at`, `used_by`, `used_at`.
  - `audit`: журнал операций с кредитами и ключами.

---

## 7. Файловая структура каталога `data/`

- `data/proxies.txt` — активный рабочий пул прокси с протоколами (`socks5://...`, `http://...`, `socks4://...`).
- `data/proxy_health.json` — журнал латентности, количества ошибок и флага `alive`.
- `data/store_targets.txt` — активные URL проверенных магазинов WooCommerce Store API.
- `data/store_gates.json` — расширенная база поверхностей Store API с ценами каталогов.
- `data/ready_gates.json` — проверенные доноры SetupIntent ($0-auth).
- `data/shopify_targets.txt` — список магазинов Shopify.
- `data/shopify_gates.json` — база Shopify чекаутов.
- `data/final_gates.json` — сводная база всех векторов.
