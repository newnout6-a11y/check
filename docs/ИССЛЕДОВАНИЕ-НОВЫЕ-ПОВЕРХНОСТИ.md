## 2. Векторы — детально

### В1. Stripe Checkout /hit — ПРИОРИТЕТ #1 (движок совместим)

Формат сцены (готовый UX, скопирован из чатов):

    /hit https://checkout.stripe.com/c/pay/cs_live_XXX...#fid... cc|mm|yy|cvv
    /hit URL cc1 cc2 cc3 (до 10 карт на один линк)
    reply на сообщение с картами + /hit URL

- **cs_live-линки** = Checkout Session с client_secret в #fid...-фрагменте URL. после decline PI возвращается в requires_payment_method → сцена бьёт до 10 карт по одному линку. наш confirm_gate + retry-loop уже это умеет; не хватает только: парсинг cs_live-URL (достать PI из фрагмента) + команда-гейт в боте
- **hCaptcha** на checkout.stripe.com — жалобы хиттеров (hitter always sed Hcaptcha required); наш fetch_hcaptcha_radar_token уже добывает P1_-токены
- **донорские домены из чатов** (готовые цели): pay.1vpn.org (VPN), checkout.wispr.ai (AI), pay.opus.pro, pay.langdock.com, buy.stripe.com/dr... (Payment Links — создаются мерчантом без кода, живут долго)
- официальный факт (docs.stripe.com): Checkout Session — объект с id cs_live_..., hosted-страница использует ту же пару токенизация+confirm, что у нас

### В2. Shopify Payments — ПРИОРИТЕТ #2 (новый контур)

- вердикты сцены: ORDER_PAID, ORDER_PLACED, INSUFFICIENT_FUNDS, OTP_REQUIRED — вывод с разбором [Min Prod | Tax | Ship] (Min Prod $1.19-12 в примерах)
- **градация гейтов**: Shopify Low ($0.50–$5) и Shopify High ($10–$15) — у нас /st 1|5|20, один в один
- **дорки сцены**: site:myshopify.com inurl:checkout, /dork shopify checkout
- Full Source Code of Shopify Checker On sell — сорсы продаются, метод в доках не описан; механика = собственный чекаут Shopify (не Stripe-API)
- для нас: **новый модуль** (не совместим с gate_client), самый большой объём сцены после Stripe

### В3. Adyen Hosted Checkout / payment links

- eu.adyen.link/PL... — публичные платёж-линки; по докам Adyen живут до 70 дней, hosted-страница истекает ~1 час после создания
- Adyen Inbuilt CCN Hitter — доноры из чатов: viu.com (видео-топап, success-URL sub.viu.com/adyen-payment-redirect), scalacube.com (Minecraft-хостинг, success: /event/invoice/paid/node_extend)
- Adyen Tesla Charged 1$ — API-чардж; adyen updated his security for viu — защита усиливается
- реплика сцены: braintree and adyen is hard… others work by catching request and changing/adding saved bin info — для Adyen/Braintree нужен перехват+подмена BIN-данных, простые replay не катят
- список платформ одного pixel-хиттера: Adyen, Braintree, Checkout.com, **Paddle, Steam, Xsolla, NordVPN** — дополнительные цели на заметку

### В4. Square

- токенизация: pci-connect.squareup.com/v2/card-nonce (applicationId sq0idp-... + locationId с витрины магазина) → CreatePayment
- донор из чатов: pecsusa.com (Square_Credit_Card)
- по докам Square — SqPaymentForm/Web Payments SDK; nonce одноразовый, генерится только их JS (anti-fraud)

### В5. Braintree — быстрый выигрыш для /vbv

- Braintree Auth.py (7.6 КБ) гуляет в чатах — реализация простая; гейты: Braintree Auth HQ FAST, Braintree Non-VBV
- наш braintreenvbv уже в боте, **не хватает только целей**: сканер уже ловит BRAINTREE_KEY-маркеры (client_token/tokenization_key) — прогнать по очереди domains.db

### В6. Прочие векторы

- **Airalo [/air]** — airalo.com/api/v2/users/me/cards/setup: $0-add-card как наш setupwoo, но на API-стеке (нужен JWT юзера после регистрации; в чатах ловит 401 — токен протухает)
- **Whop checkout** — whop.com/checkout/plan_... (маркетплейс цифровых товаров), хиттеры просят, готового нет
- **Google serviceactivation** — serviceactivation.google.com/subscription (29 упоминаний) — активация подписок Google, деталей мало
- **Gift cards** (Velocities GC-чат) — чек гифт-балансов, смежная ниша

## 4. Инструменты сцены (не платформы)

- **PixelZero** (BETA/ALPHA, 7.4 МБ в чатах) + **AR hitter** (vercel-хост) — браузерные хиттеры: headless + фингерпринт-подмена (Canvas/WebGL noise — цитата: подмени getParameter(UNMASKED_RENDERER_WEBGL))
- наш подход API-шный (curl_cffi-имперсонация) — браузерный вектор = план Б против сильных антиботов

## 5. Что делать нам (приоритеты)

1. **Stripe Checkout /hit** — движок на 90% готов (confirm_gate + hcaptcha + retry). доработка: парс cs_live-фрагмента → PI, гейт в боте, сбор доноров (buy.stripe.com-линки дорками). самый быстрый новый вектор
